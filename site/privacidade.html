Política de Privacidade — Agenda Odontológica Dente Sempre

Última atualização: 4 de novembro de 2026

1. Quem somos

A Agenda Odontológica Dente Sempre é um software de gestão de agenda para clínicas odontológicas, desenvolvido e operado pela Clínica Odontológica Dente Sempre.

2. Dados que coletamos

  • Dados da clínica (nome, código, usuários).
  • Dados de pacientes inseridos pela clínica (nome, telefone, consultas).
  • Dados de pagamento (processados pelo Mercado Pago).

3. Como usamos os dados

  • Para fornecer o serviço de agenda e sincronização.
  • Para processar pagamentos.
  • Para suporte técnico.

4. Compartilhamento

Não vendemos dados. Compartilhamos apenas com:

  • Mercado Pago (para pagamentos).
  • Prestadores de infraestrutura (hospedagem).

5. Segurança

Os dados são armazenados em servidores protegidos. A comunicação é criptografada (HTTPS).

6. Direitos dos titulares (LGPD)

A clínica é a controladora dos dados dos pacientes. Os pacientes podem solicitar acesso, correção ou exclusão diretamente à clínica.

7. Retenção

Os dados são mantidos enquanto a clínica tiver uma conta ativa. Após o cancelamento, os dados podem ser excluídos mediante solicitação.

8. Contato

Para questões de privacidade: suporte via WhatsApp ou Instagram @dentesempre.
